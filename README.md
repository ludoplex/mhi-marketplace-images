# MHI Marketplace Images

Public marketing imagery for Mighty House Inc. Odyssey vendor marketplace course listings.

All images are 1200×800 JPEG, comprised of Unsplash-licensed photography (free commercial use, no attribution required) overlaid with Mighty House Inc. branding via the Pearson Skilling Suite partner program.

## Usage

These images are referenced in the `imgs` column of Odyssey vendor CSV uploads for:
- Wyoming ESA (Steamboat Legacy Scholarship)
- Utah Fits All
- Texas Education Freedom Accounts
- and other state ESA programs Mighty House Inc. participates in.

Public-only marketing collateral. No code, no configuration, no secrets.
